# 🇮🇳 India Weather Map

An interactive Android application built with Kotlin and XML that allows users to explore the map of India, search for locations, and get real-time weather updates.

## ✨ Features
* **Interactive Map:** Pan and zoom across India (powered by OpenStreetMap).
* **Tap to Explore:** Tap anywhere on the map to drop a pin and view the weather for that exact coordinate.
* **Smart Search:** A professional search bar with autocomplete to quickly find cities and towns in India.
* **Real-Time Weather:** Displays current temperature, condition, and wind speed.
* **Modern UI/UX:** Slide-up animated weather card with custom weather icons and loading spinners.

## 🛠️ Technologies Used
* **Frontend:** Kotlin, XML, WebView
* **Map Engine:** Leaflet.js
* **APIs:** 
  * Open-Meteo (Weather data)
  * Nominatim (Place search and reverse geocoding)

## 🚀 How to Run
1. Clone this repository.
2. Open the project in Android Studio.
3. Run the app on an emulator or physical device (Requires Internet connection).
